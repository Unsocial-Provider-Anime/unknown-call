# Unknown Call Frontend

React 19 and TypeScript dashboard built with Vite, TanStack Router, TanStack Query, MUI, and Zod.

## Development

Install dependencies with `npm install`, then run `npm run dev`. Vite serves the frontend at `http://localhost:5173` and proxies `/api` requests to the backend at `http://localhost:8000`.

## Routes

- `/` displays call records. Search, country, and date filters are validated route search parameters and can be shared in a URL.
- `/analysis` displays call-volume, hourly distribution, and day-of-week analytics.

TanStack file routes compose feature modules. `src/features/call-logs` and `src/features/analytics` own their API schemas, query options, domain logic, and presentation. `src/shared/api` contains only domain-neutral transport behavior. `src/routeTree.gen.ts` is generated by the TanStack Router plugin and should not be edited by hand.

## Verification

Run these commands from `frontend/`:

```sh
npm run lint
npm run build
npm run test:e2e
```

Playwright starts a local Vite server and mocks API responses, so browser tests do not require the backend to be running.
